💡 How to read the VDL — كيف تقرأ الـ VDL
Straight parallel lines — خطوط مستقيمة واضحة
Strong, even vertical "railroad tracks" = pipe arrivals = poor bond / free pipe. The energy is trapped in the casing.
خطوط عمودية قوية ومنتظمة = موجة الأنبوب = ترابط ضعيف (الطاقة محبوسة في الغلاف).
Wavy / chevron pattern — أنماط متموجة
Irregular, chaotic, chevron (V) shapes = formation arrivals = good bond. Energy crossed the cement into the rock.
أنماط متموجة غير منتظمة = وصولات التكوين = ترابط جيد (الطاقة عبرت للتكوين).
⚠ Tip: strong straight lines can also mean a microannulus (tiny gap). Check CBL: high CBL → free pipe; low CBL with straight lines → microannulus.  —  الخطوط المستقيمة قد تعني microannulus أيضاً: إذا CBL عالٍ فهو أنبوب حر، وإذا CBL منخفض مع خطوط مستقيمة فهو microannulus.

🌟 Cement Quality — Classification Breakdown
🔨 CBL + VDL Combined Interpretation Engine
STEP 1 — CBL Classification (4-Class Unified System)
  CBL ≤ 10 mV → EXCELLENT  |  CBL 10–30 mV → MEDIUM  |  CBL 30–80 mV → POOR  |  CBL > 80 mV → FREE PIPE
Weatherford RBT (BI-Direct path): when a Bond Index (BI) curve is present, classification uses BI directly → BI>80=Excellent, 60–80=Good, 40–60=Partial, 20–40=Poor, <20=Free Pipe. The CBL Class column then shows "BI-BASED". BI scale is auto-detected: values in 0–1 are read as a fraction (×100), values in 0–100 are read as a percentage — both are handled automatically.

STEP 2 — VDL Pattern Analysis (Confirmation Tool)
  → "Strong Formation Response": Weak pipe signal, strong formation arrivals, continuous pattern
  → "Partial Formation Response": Moderate pipe + moderate formation signals
  → "Dominant Pipe Response": Very strong pipe signal (>65% energy), minimal formation
  → "Irregular Waveform Pattern": Abrupt alternating responses, low continuity — Possible Channeling only
  → "Residual Pipe Signal": Significant pipe with good continuity — CBL GOOD → Possible Microannulus
Requires a real waveform (≥2 samples/depth, e.g. Schlumberger TT1–TT8 or Weatherford radial AMMP[ ]). On the Weatherford BI-Direct path the VDL pattern is still computed and shown in the Analysis Table as confirmation, while the final interpretation stays BI-based. A single-column VDL[0] (1 sample/depth) is a placeholder, not an analysable waveform.

Bond Index (BI) = [log₁₀(Ameas) − log₁₀(Afree)] / [log₁₀(A100%) − log₁₀(Afree)]
Standard logarithmic formula (Grosmangin 1960; API RP 10TR-1). Afree = 80 mV (free pipe), A100% = 2 mV (fully bonded). Casing amplitude is logarithmically related to the fraction of circumference bonded. BI > 80% = good cement per industry convention.

⚙ Possible Channeling — Strict 3-Condition Rule
  Requires ALL three: (1) CBL > 30 mV  (2) VDL = Irregular Waveform Pattern  (3) Bond Index < 50%
  If any condition fails, the depth is NOT classified as channeling.
⚙ Baker Hughes CBL Normalization Rule
Baker Hughes attenuation curves (ATAV, ATMN, ATMX, ATC1–ATC6) are measured on a native 0–20 scale, unlike the 0–100+ mV scale used by Schlumberger, Halliburton, and Weatherford.

Normalized_CBL = Original_CBL × 5

Normalized values are used ONLY for: cross-vendor comparison, unified plotting, Bond Index calculation, and the final interpretation engine. Original Baker values remain stored and visible in the analysis table (shown as "Raw" under the CBL column) and in CSV export.

Applied ONLY when Service Company = Baker Hughes, or Baker attenuation curves (ATAV/ATMN/ATMX/ATC1–6) are detected. Schlumberger, Halliburton, and Weatherford amplitudes are never normalized — their native scales are used directly.
🏵 TOC Detection Method
Sliding window analysis (window = 5% of data) on Bond Index time series.
TOC = first depth where running avg Bond Index transitions from <40% to ≥40%.
Confidence = transition strength x 120 (capped at 99%)
Works on both the CBL-derived Bond Index and the Weatherford direct BI curve.
📁 Supported Files & Large-Data Handling
Accepted formats: .las (LAS 2.0 text) and .dlis (RP66 V1 binary).
  • DLIS files are decoded in-browser and converted to LAS automatically. If a vendor-specific DLIS cannot be decoded, the tool reports it clearly and recommends exporting to LAS.
  • Large LAS files (> 60 MB) are read in 16 MB chunks and auto-down-sampled (keeping every Nᵗ depth) so they fit in browser memory — a notice shows the ratio (e.g. 1:4) and how many of the original depths are displayed.
  • Array/radial waveform columns such as Weatherford AMMP[0…n] / IMMP[0…n] are expanded and detected as a real VDL waveform.
Down-sampling affects display and statistics only; the classification logic and thresholds are unchanged.
