Standard working sequence

Follow the tabs left to right. Each step feeds the next, so the engine always recalculates automatically after any change — there is no separate "solve" button.

Step 0 — Compass (directional survey, optional)

  1. Open the Compass tab and enter directional survey stations (MD, Inc, Azi) — row by row or pasted from Excel — or leave the default two-station vertical profile for a vertical well.
  2. The engine solves TVD, N/S, E/W and dogleg severity (DLS) between stations by the minimum-curvature method. The Compass Rose plots the plan-view path; the profile chart plots TVD vs vertical section.
  3. Press Apply Computed TVD to CasingSeat TD to carry the survey's true vertical depth into the Well TD field used by CasingSeat and StressCheck below.

Step 1 — Formation Data

  1. Open the Formation Data tab.
  2. Enter TVD (m), pore pressure (sg) and fracture gradient (sg) row by row, or paste all three columns straight from Excel with the paste box.
  3. Values above 5 are auto-detected as ppg and converted to sg (÷8.345); a status message confirms it.
  4. Check the plotted profiles look continuous — the whole design rests on this table.

Step 2 — CasingSeat (seat selection)

  1. Set Well TD, trip margin, kick margin, kick intensity and the differential-sticking limit.
  2. Choose the solution method (Bottom-up walks from TD upward) and either fix the number of strings or leave Auto to let the mud window decide.
  3. Press Calculate Casing Seats. Read the staircase on the Mud Window plot and the PASS/TD flags in the Casing Program table.
  4. Press Apply Seats to String Designs to push the shoes into the tubular design.

Step 3 — Tubular design (per string)

  1. Select a string in the Well Explorer tree on the left.
  2. In String Sections set OD, weight, grade and the bottom depth of each section. Tapered strings: add a row per section — the engine evaluates every section and reports the minimum safety factor over the whole string.
  3. Set mud weight (sg), TOC and hole size for the string.
  4. Enable H2S sour service and set the service temperature if required; the grade list is then filtered to NACE-acceptable grades.

Step 4 — StressCheck (load cases)

  1. Choose the External profile (burst backup) at the top of the load-case panel — this is the single most influential setting when comparing against StressCheck.
  2. Tick the burst, collapse and axial load cases that apply, and edit each case's parameters. Parameters are pre-filled from the well data.
  3. Production-only cases (e.g. Tubing Leak) are greyed out on drilling strings by design.
  4. Read the Load Case Results table: governing depth, load, rating at that depth, minimum SF and PASS/FAIL for every case.
  5. Open the Debug strip to inspect σh, σr, σa and the von Mises stress for every case at any depth you type in. It is read-only and never changes results.

Step 5 — Design factors & SF display

  1. Set burst / collapse / tension / triaxial design factors in Design Factors.
  2. Normalized SF (default, matches StressCheck's "Norm" columns): displayed SF = SF ÷ DF, pass at ≥ 1.00. Untick it for Absolute SF = rating ÷ load, pass at ≥ DF.
  3. Always confirm both packages are on the same display mode before comparing numbers.

Step 6 — Report & output

  1. Open Design Report for the casing program, governing safety factors, seat-selection basis and all design plots.
  2. Print / PDF re-renders every chart at full size before printing, so plots are never clipped.
  3. Save PNG under any figure exports that single plot; Save all plots exports all of them, named by well and figure number.
  4. Save writes the whole project to JSON; Open restores it (legacy ppg projects convert automatically).

Practical cautions

  • Section order matters on tapered strings — put the heavier/stronger pipe where the load is worst (usually the top for burst).
  • Burst load cases are only as good as the external profile chosen; for surface and conductor strings Pore pressure w/ seawater gradient is normally correct.
  • The engine is a single-string design tool, exactly like StressCheck; strings are checked independently.

Engine methodology

Depths in metres, densities in specific gravity, pressures in psi. Hydrostatic pressure: P = 0.433 · ρ(sg) · TVD(ft).

Collapse — API TR 5C3 four-regime model

Empirical factors are computed from the (tension-reduced) yield strength:
A = 2.8762 + 0.10679e-5·Yp + 0.21301e-10·Yp² − 0.53132e-16·Yp³
B = 0.026233 + 0.50609e-6·Yp
C = −465.93 + 0.030867·Yp − 0.10483e-7·Yp² + 0.36989e-13·Yp³
The regime is selected by D/t:
RegimeCollapse pressure
YieldPc = 2·Yp·(D/t − 1)/(D/t)²
PlasticPc = Yp·(A/(D/t) − B) − C
TransitionPc = Yp·(F/(D/t) − G)
ElasticPc = 46.95e6 / [(D/t)·(D/t − 1)²]
Combined loading: where axial stress is tensile the effective yield is reduced, Ype = Yp·(√(1 − 0.75r²) − 0.5r), r = σa/Yp, applied point-by-point so the collapse rating varies with depth as tension changes.

Burst — Barlow internal yield

Pburst = 0.875 · 2 · Yp · t / OD — 87.5 % minimum wall, t = (OD − ID)/2.

Triaxial — Lamé / von Mises

Thick-wall stresses at the inner wall:
σz = Fa/As, σh = [pi(ri²+ro²) − 2poro²]/(ro²−ri²), σr = −pi
σVME = √{ ½[(σz−σh)² + (σh−σr)² + (σr−σz)²] }
Each load case is paired with its own external pressure profile and with the post-cement (service) axial profile, because service pressures act on a cemented string. The design envelope solves σVME = Ylimit on the burst branch (po = 0) and collapse branch (pi = 0) to draw the von Mises ellipse.

Axial

Buoyancy factor BF = 1 − ρmud(sg)/7.84; body yield Py = 0.7854·(OD² − ID²)·Yp.
Running in hole adds the shock load from stopping the string instantaneously, Fshock = 0.9161 · Vavg · As · √(E·ρsteel) (the peak-to-average factor of 1.5 is already contained in the coefficient).
Post-cement static uses the piston formulation with the real fluid columns — displacement fluid inside, mud above TOC and slurry below outside — because the cement is still fluid immediately after the job and does not yet support the pipe.
Service loads aggregate the post-cement profile with the end-piston force from the largest enabled internal service pressure and the thermal term ΔF = −α·E·As·ΔT (α = 6.9e-6/°F, E = 30e6 psi).

Safety factor display

Absolute: SF = rating ÷ load, minimum tolerable value = the design factor.
Normalized: SF = rating ÷ (load × DF), minimum tolerable value = 1.00 by definition. This matches the "Norm" columns of StressCheck's Well Summary. The triaxial default DF of 1.25 is 8/7 of the burst DF of 1.10, reflecting the 12.5 % wall reduction in the API burst rating.

CasingSeat

Mud to drill the next hole = maximum pore pressure over that section + trip margin. Kick EMW at the shoe = mud + KI·(D/S). A shoe is accepted at the shallowest depth where the kick EMW stays below (fracture − kick margin). Differential sticking is screened as the worst overbalance against the shallowest normally-pressured sand, compared with the specified limit.

Sour service

NACE MR0175 / ISO 15156-2 grade acceptability, applied as a temperature-dependent filter on the grade list when H2S service is enabled.

Known limitations

  • Gas kick uses a static envelope of the Driller's-Method bottom-hole pressure, not a full bubble-migration circulation with a Redlich-Kwong gas EOS.
  • Service loads omit buckling and bending; landing pick-up / slack-off is not yet an input.
  • Ratings use nominal yield — temperature de-rating of yield strength is not applied.
  • The Compass tab computes true TVD/N/E/DLS from a directional survey by minimum curvature, but the stress-check engine itself still treats the string as straight — dogleg-induced bending pseudo-loads are not added to the axial/triaxial loads.

Unit conventions

  • Depth in metres (TVD), pressure in psi, density in specific gravity.
  • Density entries above 5 are treated as ppg and converted automatically (÷ 8.345).
  • Gas gradients stay in psi/ft — they are gradients, not densities.
